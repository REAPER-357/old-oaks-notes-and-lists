# Old Oak Notes & Lists

**Old Oak Notes & Lists** is a feature-rich, local-first productivity web application designed for fast and efficient note-taking and task management. Built with a rustic aesthetic and modern tooling, it runs entirely in the browser with zero external dependencies other than Tailwind CSS and Lucide icons. **Currently Bug Testing**

## Features

- **Dual Modes:** Seamlessly switch between **Notes** and **To-Do Lists** via dedicated tabs[cite: 2].
- **Folder Organization:** Create custom folders and expand them inline with smooth accordion slide-downs to view items directly[cite: 2].
- **Drag-and-Drop:** Easily drag and drop items into folders or use multi-select mode for batch moving and deleting[cite: 2].
- **Favorites System:** Star important items to pin them to the top of the interface for instant access[cite: 2].
- **Sorting & Search:** Real-time search across titles and content, with instant sorting options (Newest/Oldest, A-Z, Z-A)[cite: 2].
- **Compact UI:** Ultra-clean single-line item view maximizing screen space[cite: 2].
- **Data Backup & Restore:** Export your entire vault as a JSON backup or perform a **Safe Merge Import** that preserves existing IDs without overwriting current data[cite: 2].
- **Theme Support:** Clean Dark and Light mode toggles (Dark mode enabled by default)[cite: 2, 3].
- **Progressive Web App (PWA) Ready:** Includes a manifest[cite: 3] and service worker[cite: 5] for offline caching.

## Tech Stack

- **HTML5 / CSS3**
- **Tailwind CSS** (via CDN with custom color configurations)[cite: 2]
- **JavaScript (Vanilla)** with local storage persistence[cite: 2, 3]
- **Lucide Icons**[cite: 2]

## Installation & Local Usage

1. Clone or download the repository to your local machine.
2. Ensure all asset files (`index.html`, `small-icon.png`, `icon.png`, `manifest.json`, `sw.js`) are in the same directory.
3. Open `index.html` in any modern web browser or host it via a local static server (e.g., GitHub Pages[cite: 2]).
